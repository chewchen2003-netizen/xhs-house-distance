# 看房距离助手 · 小红书

> 刷小红书找房时，直接看到这套房子离你公司多远、地铁要多久、打车多少钱 —— 不用再复制小区名去地图软件搜一遍。

![信息流角标](docs/preview-feed.png)

一个 Chrome / Edge 扩展（Manifest V3），在你刷 `xiaohongshu.com` 时工作：

- **信息流卡片**：标题下面自动多一行 `距公司 3.2km · 🚇32min`
- **笔记详情**：把笔记里提到的小区自动列成清单，按离你的距离排序
- **评论区**：提到小区的评论下面挂一条距离标签
- **划词查询**：选中任意小区名直接查
- **收藏**：收藏「小区」而不是帖子，按通勤排序，一键复制清单发微信

![笔记详情清单](docs/preview-detail.png)

点开任意一条，是完整通勤：

![通勤详情](docs/preview-panel.png)

## 安装

> 这是「未打包扩展」，不需要上架商店，本地加载即可。安装后**不要移动或删除**这个文件夹。

### macOS

1. 下载或 `git clone` 本项目到本地
2. Chrome 打开 `chrome://extensions`
3. 打开右上角 **「开发者模式」**
4. 点左上角 **「加载已解压的扩展程序」**，选择**本项目根目录**（有 `manifest.json` 的那一层）
5. 工具栏出现红色定位针图标即成功

也可以直接双击项目里的 `一键安装.command`，它会打开扩展页并把路径复制到剪贴板。

### Windows

1. 下载并解压本项目
2. Chrome / Edge 打开 `chrome://extensions`
3. 打开右上角 **「开发者模式」**
4. 点 **「加载已解压的扩展程序」**，选择解压后的文件夹（有 `manifest.json` 的那一层）
5. 工具栏出现红色定位针图标即成功

> Edge 用 `edge://extensions`，步骤相同。

## 第一次用：设置你的地点

1. 打开 <https://www.xiaohongshu.com/explore>
2. 右下角红色圆按钮会自动弹出面板
3. 第一行填备注名（如 `公司`），第二行搜地点（如 `国贸三期`），点「搜」→「选它」

想加第二个地点（健身房、朋友家）就再点一次「+ 地点」。卡片角标上显示的是**第一个地点**。

## 信息是怎么算的

| 信息 | 来源 | 说明 |
| --- | --- | --- |
| 直线距离 | 两点球面距离 | 第一轮筛选用：3km 内通勤友好，10km 以上基本可以划走 |
| 地铁方案 | 百度地图公交规划 | 真实线路/时长/票价/步行距离；按「时间 + 步行时间×0.5」排序，避免推荐「走 3 公里」的方案 |
| 打车 | 百度地图驾车规划 | 里程、时长、按北京出租车计价规则的预估价；**时长不含实时拥堵**，仅供参考 |
| 最近地铁站 | 百度地图周边检索 | 2.5km 半径内最近的已开通地铁站 |

坐标全部来自百度地图 POI，与小红书无关。请求串行、间隔 ≥320ms，结果本地缓存（路线 7 天、小区 14 天）。

**为什么卡片上只放两个数字**：信息流一屏十几张卡，堆满「地铁 32 分钟 / 打车 ¥37 / 步行 800m」会失焦。卡片只给 `距离 + 地铁时长`，其余收进点开的详情卡。

## 手机 / 给朋友用

`mobile/index.html` 是一个**单文件网页**，不依赖服务器、不需要 API key，iPhone / Android 都能用：

复制小红书笔记文字 → 打开网页 → 粘贴 →「查距离」，一次识别所有小区，按距离排序，点开看地铁/打车/地铁站，能收藏、能跳高德。

```bash
# 本地预览
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123/mobile/
```

发给她：AirDrop / 微信发文件，或把文件丢到 GitHub Pages / Vercel 等静态托管，得到一个链接（支持 `?q=望京西园三区` 直接带参数）。

![手机版](docs/preview-mobile.png)

> iOS 不允许往第三方 App 注入界面，所以「小红书 App 内自动显示」在 iPhone 上做不到；
> 桌面端是真实插件，手机端是上面这个网页。

## 项目结构

```
.
├── manifest.json          # MV3 配置
├── background.js          # Service Worker：百度 POI 检索、路径规划、缓存、右键菜单
├── lib/
│   ├── geo.js             # 百度墨卡托 ↔ 经纬度、BD09→GCJ02、球面距离、地图链接
│   └── detect.js          # 从中文文案里抽小区名 + 与 POI 名的相似度打分
├── content/
│   ├── content.js         # 页面内 UI：悬浮面板、卡片角标、详情清单、评论区、划词
│   └── content.css
├── popup/                 # 工具栏弹窗：地点管理、查距离、开关
├── mobile/index.html      # 手机版单文件网页
├── icons/
├── docs/                  # README 用截图
└── test/                  # 本地测试台（假数据，不联网）
```

## 开发

```bash
# 本地测试台：模拟小红书信息流 / 笔记详情 / 评论区
python3 -m http.server 8123
open http://127.0.0.1:8123/test/site/explore/

# 用真实百度接口跑一遍取数 → 匹配 → 地铁 → 缓存
node test/background.test.js
```

改完代码后，在 `chrome://extensions` 点扩展卡片上的 ↻ 刷新即可。

- 地理数据来自百度地图网页版公开接口（无需 key），请勿滥用；已做限速与缓存。
